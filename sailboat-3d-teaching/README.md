# ⛵ 交互式 3D 帆船教学系统（Three.js + Vite）

一个面向航海科普 / 帆船结构教学的可交互 3D 项目：可 360° 观察帆船、透视查看内部结构、
调节风向风速模拟真实航行状态（帆角联动、船体侧倾、波浪起伏），并可点击 10 个核心部件
查看作用与航行原理讲解。

---

## 一、功能清单

| 模块 | 功能 |
| --- | --- |
| 自由视角 | OrbitControls：左键拖拽旋转、滚轮缩放、右键平移；可开关自动环绕预览 |
| 透视模式 | 全局半透明透视（船壳/桅杆/索具变透明，可看内部与水下龙骨）；选中部件单独高亮 |
| 风参数控制 | 风向 0–360°、风速 0–30 m/s 滑块，配风向罗盘 |
| 帆角联动 | 主帆、前帆随风向自动转动，模拟迎风 / 横风 / 顺风等航行状态（points of sail） |
| 船体侧倾 | 风速越大侧倾越大，方向朝背风一侧；飘帆区帆面高频抖动 |
| 波浪海面 | 三波叠加的顶点动画海面，船身按波面采样升沉、纵摇、横摇 |
| 模拟控制 | 一键启停（暂停时全系统冻结）、重置到初始状态（含视角复位） |
| 部件讲解 | 10 个部件可点击高亮，右侧面板讲解作用、航行原理、知识要点 |
| 部件目录 | 左侧面板列出全部部件，点击等同 3D 拾取 |
| 写实光照 | 环境光 + 半球光 + 带 PCF 软阴影的方向光（太阳），ACES 色调映射 |

### 可讲解的 10 个部件

船壳 Hull、主桅杆 Main Mast、前桅杆 Fore Mast、主帆 Mainsail、前帆 Jib、
舵 Rudder、龙骨 Keel、稳向板 Centerboard、缭绳 Sheets、帆桁 Boom。

## 三、运行步骤（npm）

> 环境要求：Node.js **18 及以上**（推荐 20 LTS）。

```bash
# 1. 进入项目目录
cd sailboat-3d-teaching

# 2. 安装依赖
npm install

# 3. 启动开发服务器（自动打开浏览器 http://localhost:5173）
npm run dev

# 4. 生产构建（输出到 dist/）
npm run build

# 5. 本地预览构建产物
npm run preview
```

**不下载任何外部模型也能完整运行**：默认使用内置程序化帆船（部件命名完整、拾取最可靠）。

## 六、航海原理说明（模拟模型依据）

### 1. 帆为什么能推进船（翼型升力）
风吹过鼓起的帆面时，帆形成类似机翼的弧形：背风凸面气流快、压力低，
迎风凹面压力高，压差产生近似垂直帆面的**升力**。其前进分力推动船航行，
横向分力使船横移与侧倾，由水下龙骨产生反向水动力抵消。

### 2. 三种基本航行状态（Points of Sail）
- **迎风航行（Close-hauled）**：风与船头夹角约 38°–80°，帆收得很紧，侧倾明显；
- **横风航行（Beam reach）**：夹角约 80°–100°，风从正侧方来，翼型效率最高，通常航速最快；
- **顺风航行（Running）**：夹角接近 180°，帆被风从后方推着走，帆桁几乎横张。
- 夹角小于约 38° 时无法形成有效翼型，帆会抖动**飘帆（luff）**——帆船不能正对风航行，
  需以"之"字形迎风换舷（tacking）曲折前进。

### 3. 船体侧倾（Heel）
帆上的风压力作用点高于水面，与龙骨的水下反作用力形成**力偶**，使船向背风一侧倾斜。
本项目中侧倾角 ∝ 风速 × 帆效系数，并封顶在 28°（真实帆船常见范围 15°–30°）。

### 4. 龙骨与稳向板
- **龙骨 Keel**：固定重型鳍（常含铅质压载），抗横漂 + 压载扶正，适合远洋但吃水深；
- **稳向板 Centerboard**：可收放的轻型板，靠水动力抗横漂，浅水可提起，常见于小帆船。

### 5. 舵
舵叶偏转后与来流形成攻角，产生侧向水动力形成转船力矩；船速越高舵效越好，
静止时舵失灵。

## 八、常见问题

**Q：启动后是低模程序化帆船，不是真实模型？**
A：这是默认回退模型。按「第四节」放入 `public/models/sailboat.glb` 即自动替换。

**Q：点不中缭绳？**
A：拾取器已为线对象设置 0.25 的射线容差（`picker.js` 中 `Line.threshold`），
点击绳段附近即可；也可直接用左侧部件目录选择。

**Q：暂停后海面也不动了？**
A：模拟与海面共用时间轴，暂停即全系统冻结，便于静止讲解；再次点击「模拟」恢复。
